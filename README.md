## 📖 Descripción del Laboratorio

Ejercicios de composición visual utilizando el modelo de caja flexible (Flexbox), alineaciones avanzadas y el elemento nativo `<details>` / `<summary>` para acordeones.

---

## 🎯 Objetivos y Requisitos Técnicos

- [x] Alineación bidireccional (`justify-content`, `align-items`, `align-content`)
- [x] Propiedades de crecimiento y reducción (`flex-grow`, `flex-shrink`, `flex-basis`)
- [x] Acordeones nativos con `<details>` y `<summary>` sin JavaScript
- [x] Diseño de layouts modulares y reutilizables

---
